## about

i like small, fast, terminal-first software.  
less noise. more control. tools that feel sharp in the hand.

- building **kerf**, a polished TUI coding agent in Guile Scheme
- working close to the metal: shell, window managers, configs, and workflows
- interested in local models, agent tooling, and clean interfaces
- prefer minimal dependencies and direct, readable code

## featured project

### [kerf](https://github.com/zankros/kerf)

a fast, polished terminal coding agent with:

- tabbed start page and compact chat view
- OpenAI-compatible and local-model support
- native tool calls plus text fallback for models like qwen
- saved server profiles, quick connect, import, and tests
- OpenCode-style tools: `bash`, `read`, `write`, `edit`, `list`, `grep`, `glob`,
  `patch`, `webfetch`, `todowrite`, `todoread`
- one-line installer and Makefile install

```sh
curl -fsSL https://raw.githubusercontent.com/zankros/kerf/master/install.sh | sh
```
